# solana projects

collection of solana smart contracts and programs

## anchor programs

**calculator** - basic calculator program with arithmetic operations (add, subtract, double, halve)
[view source](anchor/calculator/programs/calculator/src/lib.rs)

**cpi_contract** - demonstrates cross-program invocation (cpi) for sol transfers using anchor
[view source](anchor/cpi_contract/programs/cpi_contract/src/lib.rs)

**cpi_sol_transfer** - demonstrates cross-program invocation for sol transfers using system program invoke
[view source](anchor/cpi_sol_transfer/programs/cpi_sol_transfer/src/lib.rs)

**staking_contract** - sol staking program with points accumulation system based on staked amount and time
[view source](anchor/staking_contract/programs/staking_contract/src/lib.rs)
